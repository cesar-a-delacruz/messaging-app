# Messaging App

![screenshot](./docs/screenshot.png)

## Overview

This this a messsaging application similar to WhatsApp for sending messages. You can send messages with text or images and also create groups with other users.

**[Check it here](https://cesar-a-delacruz-messaging-app.netlify.app)**

## Main Features

1. Send, edit and delete messages
2. Create and manage groups
3. Add and delete members into groups
4. Edit your profile including your credentials
